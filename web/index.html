The record behind the sound

What the pixels measure.

How a frame becomes a note

  1. A satellite passes It measures every pixel below it, every day or every few days.
  2. NASA maps it Each frame is a NASA GIBS map: one reading per pixel.
  3. One number a year Terra Vox averages the year’s frames into a single value.
  4. The number plays How much sets pitch, loudness and timbre. How far it has moved since the first year sets the tempo.
